# BackEnd Projeto TCC
# Rede Social para Participação Política

Esse repositório contém o BackEnd que é usado no projeto [FrontEnd-TCC](https://github.com/ArtAulas/FrontEnd-TCC).

O projeto é desenvolvimento em JavaScript, utilizando as bibliotecas Express para montagem da API e Prisma para conexão com banco de dados.

As variáveis de ambiente estão listadas no arquivo **.env.sample**

Alguns comandos importantes para utilizar corretamente o prisma são:

1. `npx prisma db push`
2. `npx prisma generate`
3. `npx prisma studio`
